03. GitHub Pages 배포 메모

  1. 새 GitHub 저장소를 만들고 이 파일을 index.html 이름으로 업로드합니다.
  2. 저장소의 Settings > Pages에서 Branch를 main, Folder를 / (root)로 선택해 저장합니다.
  3. 생성된 https://<사용자명>.github.io/<저장소명>/ 주소로 접속해 바로 사용할 수 있습니다.
